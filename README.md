# Astraversa

A small wrapper around [Raylib Python CFFI](https://github.com/electronstudio/raylib-python-cffi), just enough to deal with stuff.

Details TBA.

## Installation

```bash
git clone https://github.com/RimuEirnarn/Astraversa
cd Astraversa
pip install -e .
```

By default, I uses editable so the engine can be written from this directory. If you're pulling from virtual environment, you don't need `-e` or editable mode.
